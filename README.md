# liweilun2021.github.io

Personal resume site. Static HTML and CSS, with no build step.

- Live site: https://liweilun2021.github.io
- Page content: `index.html`
- Styles: `styles.css`

Local preview:

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```

Publishing: push to the `main` branch and GitHub Pages will update automatically.
